시장영향은 각 이벤트의 트리거일 전후 실제 자산 변동을 계산한 값입니다. 전체 시장 지표가 아니라 이벤트별로 따로 산출하므로, 어떤 내러티브가 실제로 증시를 움직였는지 구분됩니다. 사분면은 관심도 대비 실제 영향을 교차한 것으로, '소음'은 뉴스는 많지만 가격에 이미 반영된 상태, '저평가 리스크'는 조용한데 자산이 움직인 상태입니다.
